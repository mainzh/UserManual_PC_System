## 系统激活

1、右键 开始菜单

2、点击 终端管理员

3、输入 `irm https://massgrave.dev/get | iex` ，回车（注意空格）

​               `irm https://get.activated.win|iex`

4、在“Activation Methods”中选择“1”激活Windows，选择“2”激活Office
